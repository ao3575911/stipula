# Roadmap

Only after the seal card is used for real.

1. Telegram Stars for the pro flag, behind the same `set_plan` method. No second quota system.
2. Optional webhook mode for hosts that already terminate TLS. Still one process.
3. A Mini App that renders the chain the bot already stores. The desk in a browser is a format demo, not this app's backend.
4. A signed export the counterparty can check without trusting a later database rewrite: publish the seal hash somewhere the operator does not control. Do not call that a blockchain until it is one.
5. Per-chat retention policy for admins.

Not planned: username escrow, anonymity claims, storing file bytes, or inventing a signature scheme.
